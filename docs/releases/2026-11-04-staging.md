# Staging update · November 4, 2026

This release updates staging only. Production code, services, scheduled analysis and published AI caches are unchanged.

- **Period comparison:** Reporting and comparison selectors, swap dates and metric PoP across Overview and the testing channels. Prompt trials default to Previous period (PoP), so Last Week compares with the week before. Missing comparison data remains unavailable.
- **Bilingual insights:** New channel, Campaign and Overview reports combine channel-specific analytical prompts with the Readability rules. Campaign deep dives, charts, creative previews and action priorities use an isolated, validated report bundle. Social and Reddit lifetime reports are included. The bundle covers October 27–November 2, compared with October 20–26; other periods retain their existing published analyses.
- **Prompts:** A staging workspace lists rules in the order Master rules, Overview, Readability, then channel and supporting prompts. Users can inspect consumers, edit and save account-signed versions, review differences and restore earlier content as a new version.
- **Insight previews:** All channel and Overview scopes are connected. Campaign selection uses the shared Ask AI menu; dates and comparison controls reuse existing selectors. Trials capture prompt versions and frozen Dashboard data, preserve saved results, compare previews and reuse completed analysis for Readability or translation. Saved edits do not activate production daily prompts.
- **Ask AI in Prompts:** The button sits at the right of the Edit & versions / Insight preview tab bar. Opening captures the selected prompt, unsaved draft, trial scope/dates/language and displayed result. Chat discusses this page content without automatically saving or generating a trial. Staging conversations use the dedicated Prompt queue/native worker, preserving per-user history and cancellation without production bridge credentials or production chat-table writes.
- **Layout and language:** Aligned responsive trial form, independent date row, simplified descriptions, and reliable language loading/retry behavior. Metric and creative navigation preserve reporting/comparison dates.

Analysis files and private configuration are transferred separately from Git. The dedicated staging Prompt database role can write only its isolated version/preview tables. Advertising refreshes and production cache publication remain blocked. Staging release notes link to the updated areas for team review.
