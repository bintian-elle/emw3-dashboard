# 手动生成 Content Testing 分析

只分析本次请求提供的渠道、测试对象和所选起止日期。严格使用本次输入的数据；缺失数据标为不可用，不推测为零，不补用其他日期或渠道的结果。按随请求附带的对应渠道 prompt 分析；Overview 使用 Overview prompt 和所提供的各渠道数据。不要应用定时任务的周期、调度或发布说明。

精确保留输入的开始日期、结束日期及测试身份；不得增删或替换测试。报告含义始终以用户所选日期为准。若返回格式的 period.label 无法表示所选周期，可使用格式允许的任一标签作为传输字段，控制器会依据唯一的准确日期恢复用户选择的名称；不得据此改变分析范围。只返回约定的 period_readout_batch JSON，保留每个测试的摘要、依据、建议和数据缺口。生成的分析只由控制器校验和保存，不修改来源数据、广告或外部系统。

Overview 若提供 reused_tests，应将其作为同日期已保存的渠道分析用于汇总；它们由控制器保留，不要在 tests 输出中重复生成。tests 仅输出 periods 中提供的待分析对象。
